# الحیات مرکز علوم اسلامیہ
## وفاق المدارس درس نظامی بنین

یہ ویب سائٹ فراہم کردہ نصاب کو آٹھ سال، ۴۸ نصابی گروپ اور ۸۴ کتابی اندراجات میں پیش کرتی ہے۔ یہ ایک مکمل، ہلکی اور بغیر build مرحلے کے چلنے والی static website ہے۔ سال، مضمون اور کتاب کے صفحات، تلاش، سال کے لحاظ سے کتب کی چھانٹی، صفحات میں تقسیم، گہرے و روشن رنگ اور واضح واپسی کے راستے شامل ہیں۔

کتب کے اصل تدریسی مواد کے الگ روابط آپ خود درج کریں گے۔ جب تک کسی کتاب یا کورس کا ربط شامل نہ ہو، اس کے صفحے پر دستیابی کی درست حالت دکھائی دیتی ہے۔ اس پیکج میں مکمل کتب کی شروح یا تدریسی ویب سائٹس شامل ہونے کا دعویٰ نہیں کیا گیا۔

## GitHub پر چلانے کا طریقہ

1. ZIP کھولیں اور `alhayat-dars-nizami` فولڈر کے اندر کی تمام فائلیں نئی GitHub repository کی اصل سطح پر رکھیں۔ `index.html` اصل سطح پر ہونا چاہیے۔
2. GitHub Desktop سے repository کھولیں، فائلیں شامل کریں، commit کریں اور Push origin کریں۔
3. GitHub پر repository کی **Settings → Pages → Build and deployment** کھولیں۔
4. **Deploy from a branch** منتخب کرکے **main** اور **/ (root)** محفوظ کریں۔
5. Pages کا عمل مکمل ہونے پر GitHub اسی صفحے پر ویب سائٹ کا لنک دکھائے گا۔

کسی npm installation، API key، database، Cloudflare Worker یا build command کی ضرورت نہیں۔ یہی فائلیں کسی عام static hosting پر بھی چل سکتی ہیں۔ مقامی مطالعے کے لیے `index.html` براہ راست کھولا جا سکتا ہے۔

## کتاب یا کورس کا نیا ربط شامل کریں

صرف `data/resource-links.js` میں ترمیم کریں۔ اصل فائل میں نمونے تبصرے کی صورت میں ہیں۔

```js
window.HAYAT_LINKS = {
  "year-1-course-1": "https://your-real-course-url.com/",
  "year-1-course-1-book-1": "https://your-real-book-url.com/",
  "علم النحو": "https://your-real-book-url.com/"
};
```

نمونہ URLs اپنی حقیقی ویب سائٹس کے پتوں سے بدلیں۔ کوئی نمونہ ربط فعال حالت میں فراہم نہیں کیا گیا۔

- `year-1-course-1`: پہلے سال کا پہلا نصابی گروپ۔ ہر سال کے چھ اصل گروپ ہیں۔
- `year-1-course-1-book-1`: اسی گروپ کی پہلی کتاب۔
- کتاب کا نام بطور کلید دینے سے جہاں جہاں یہی نام آئے گا، وہاں مشترک ربط استعمال ہوگا۔
- ترجیح: مخصوص کتابی اندراج کا ربط، پھر مشترک کتاب کا نام، پھر متعلقہ کورس کا ربط۔
- ہر ربط نئے tab میں کھلتا ہے؛ اصل نصاب کا صفحہ کھلا رہتا ہے۔
- صرف `https://` یا `http://` روابط قبول ہوتے ہیں۔
- تمام کتابی IDs کی فہرست `docs/link-index.csv` میں موجود ہے؛ اسے Excel میں بھی کھول سکتے ہیں۔
- ترمیم کے بعد commit اور push کریں۔

## اردو اور عربی خط

اردو کے لیے جمیل نوری نستعلیق کی WOFF2 فائل خود ویب سائٹ کے ساتھ شامل ہے۔ عربی کتابوں کے نام `lang="ar"` کے ساتھ Noto Naskh Arabic میں دکھائے جاتے ہیں۔ اردو عبارت کے اندر آنے والے معروف عربی عناوین بھی الگ font span میں ہیں۔ صارف کو یہ فونٹس اپنے آلے پر نصب کرنے کی ضرورت نہیں۔ جمیل فونٹ کی مکمل فائل تقریباً ۵٫۶ MB ہے؛ `font-display: swap` کی وجہ سے اس کے آنے تک متن متبادل فونٹ میں پڑھا جا سکتا ہے، اور براؤزر اسے بعد میں cache کر سکتا ہے۔

## نصاب کی حدود

یہ اندراجات اسی PDF پر مبنی ہیں جو اس پیکج میں شامل ہے۔ انہیں کسی بعد کے تعلیمی سال کی تازہ سرکاری تصدیق نہ سمجھا جائے۔ بعض پہلے سال کی کتابیں متبادل ہیں؛ اصل PDF کی عبارت اور ہدایات کو ترجیح حاصل ہے۔ ہر کتاب کا صفحہ متعلقہ کورس کی مجموعی نصابی حد دکھاتا ہے، ساتھ یہ وضاحت بھی موجود ہے۔

حدیث کے مخصوص اعداد، منتخب حصے، حفظ، امتحانی نمبر، متبادل کتب اور مطبوعہ نسخوں کی تفصیلی حدود کے لیے اصل نصاب کے متعلقہ صفحے کا براہ راست لنک دیا گیا ہے۔ خاص طور پر دورۂ حدیث کے صفحات ۱۰–۱۱ دیکھیں۔ فہرست میں ایک کتاب کئی سالوں یا جلدوں کے تحت دوبارہ آ سکتی ہے، اس لیے ۸۴ کو منفرد کتابوں کی تعداد نہ سمجھا جائے۔

نصاب تبدیل کرتے وقت `data/syllabus.js` اور اس کی JSON نقل دونوں کو ہم آہنگ رکھیں۔ ویب سائٹ براہ راست JS فائل استعمال کرتی ہے؛ اسے JSON fetch کرنے کی ضرورت نہیں۔

## جانچ

Node.js دستیاب ہو تو اصل فولڈر میں چلائیں:

```sh
node tests/check.mjs
```

جانچ میں آٹھ سال، تمام کورسز اور کتابی صفحات، حدود سے باہر راستے، تلاش کے نتائج، pagination، سال کا filter، بیرونی URLs کی حفاظت، متن کا escaping، theme اور ضروری مقامی فائلیں شامل ہیں۔ دونوں رنگی حالتوں میں کارڈ اور بٹن کی متعین رنگی جوڑیوں کا کم از کم contrast تقریباً ۷٫۹۶:۱ ہے۔ مختلف آلات پر حتمی visual rendering کی جانچ اشاعت کے بعد بھی کریں۔
