# نسخہ ۵ — مطالعے اور آمدورفت کی بہتری

- اردو کے لیے مقامی جمیل نوری نستعلیق، عربی عنوانات کے لیے مقامی Noto Naskh Arabic۔
- حروف کے تین سائز؛ انتخاب اسی براؤزر میں محفوظ رہتا ہے۔ بڑے حروف پہلے سے منتخب ہیں۔
- سال، مضمون، کتاب، مرکزی فہرست اور صفحہ بندی کے راستے اب حقیقی روابط ہیں؛ ربط نقل کرنا اور نئے ٹیب میں کھولنا ممکن ہے۔
- ہر بنیادی صفحے پر ایک مرکزی عنوان اور اندرونی صفحات پر واضح breadcrumb۔
- صفحہ بدلنے پر کی بورڈ اور اسکرین ریڈر کی توجہ اصل مواد پر آتی ہے۔
- رہنمائی کا مختصر صفحہ، واضح ابتدائی راستے اور خالی تلاش کے بعد متبادل انتخاب۔
- موجودہ آٹھ سال، ۴۸ نصابی گروپ، ۸۴ کتابی اندراجات اور روابط کی فائل برقرار ہیں۔

## تصدیق

`node tests/check.mjs` — تمام نصابی راستے، محفوظ URLs، تلاش، سال کے filters، صفحہ بندی، رہنمائی، حروف کا سائز اور theme۔

`node tests/contrast.mjs` — کارڈ اور بٹن کی ۵۰ متعین رنگی جوڑیوں کا کم از کم تضاد ۷٫۹۶:۱؛ hero کی متعین عبارت کی جوڑیاں کم از کم ۴٫۵:۱۔

اصل HTML کی nesting اور تمام مقامی assets کے راستے بھی جانچے گئے ہیں۔ خودکار جانچ حقیقی براؤزر کی بصری جانچ کا متبادل نہیں۔ اس ماحول میں موبائل اور desktop browser کا بصری معائنہ دستیاب نہیں تھا؛ اس لیے pixel-perfect یا ہر آلے پر حتمی تصدیق کا دعویٰ نہیں کیا گیا۔
